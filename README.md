# GSB 5544 — Instructor Prep

Teaching materials for GSB 5544 (Cal Poly).

## Structure
- `assignments/Data/` — data sets (e.g. `coffee_purchases.csv`)
- `assignments/practice_activities/` — Colab notebooks
  - `*_Topic_*.ipynb` — student (fill-in-the-blank `____`) versions
  - `*-solution.ipynb` — completed versions
- `assignments/labs/`, `assignments/quizzes/`

## Notebooks
| Topic | Student | Solution |
|---|---|---|
| 1.2 Intro to Pandas | `GSB5544_Topic_1_2_Intro_to_Pandas.ipynb` | — |
| 1.3 Pandas Fundamentals | `GSB5544_Topic_1_3_Pandas_Fundamentals.ipynb` | `...-solution.ipynb` |
| 1.4 NumPy Essentials | `GSB5544_Topic_1_4_NumPy_Essentials.ipynb` | `...-solution.ipynb` |

Notebooks read the coffee data with `pd.read_csv("")` — paste the raw GitHub URL of
`assignments/Data/coffee_purchases.csv` into the quotes when running in Colab.
